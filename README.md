# CoffeeBrewery Core

## How do I install these formulae?

`brew install coffeebrewery/core/<formula>`

Or `brew tap coffeebrewery/core` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "coffeebrewery/core"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
